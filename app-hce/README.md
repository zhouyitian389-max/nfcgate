# app-hce

The NFC HCE app (App B) provides Host-based Card Emulation (HCE), allowing an Android device to emulate NFC tags. It supports importing tag data (pcapng / JSON), receiving data over an embedded HTTPS server, and replaying the data via the Android HCE stack.

**Status: skeleton (milestone 2)**

Feature implementation begins in milestone 4. The current version only contains the minimal module wiring and a launchable placeholder Activity, plus the NFC permission and HCE feature declarations in the manifest.
