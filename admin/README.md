# NFCGate Admin Panel

Next.js + Tailwind CSS 管理面板。

## Quick Start

```bash
npm install
cp .env.example .env.local
npm run dev
# → http://localhost:3001
```

## Pages

- `/login` — 管理员登录
- `/` — 仪表盘
- `/users` — 用户管理
- `/devices` — 设备管理
- `/cards` — 卡片审计
- `/logs` — 操作日志
